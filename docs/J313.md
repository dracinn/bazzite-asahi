# J313 — MacBook Air (M1, 2020)

- Apple Silicon M1 / T8103
- Device family: MacBook Air 2020
- Identifier: J313
- ARM64
- Development machine family: MacBookAir10,1

## Boot/install target
J313 is the first hardware target. The project should use the normal Asahi installation boundary rather than embedding a replacement Apple boot chain.

Expected boot path:
1. Asahi Installer prepares the Apple Silicon boot environment.
2. m1n1 and Asahi U-Boot provide the UEFI environment.
3. The EFI bootloader loads the Bazzite Asahi kernel/initramfs.
4. The Atomic image supplies the immutable OS userspace/root.

The current CI milestone is the OCI image composition layer. The next installation milestone is to prove that this image can be deployed and booted through the current Asahi UEFI environment.

The install procedure is documented in [INSTALL-J313.md](INSTALL-J313.md).

## Update lifecycle — 2026-10-16

Validator after fixes: **PASS=17 FAIL=0 MANUAL=5** (audio `AppleJ313`
green, speakersafetyd enabled+active). `bootc update` fetched a 536 MB
layer delta and staged `44.20261016.0` (`sha256:1d6485e0…`) — update
path confirmed working over tethered data; delta size is manageable.
Pending: reboot into the staged deployment, then `rpm-ostree rollback`
test. Note for future: use `bootc update` only — running
`rpm-ostree upgrade` too stages a duplicate deployment.

Boot picker note: Apple Silicon has no bootloader-level input — the
picker is a macOS app in 1TR, reached only by holding power at boot.
Per-boot choice = hold power; otherwise `asahi-bless --next` /
macOS Startup Disk switch the next boot only without changing default.

## Test policy
Do not use the developer's primary macOS/APFS installation as an automated destructive test target.

Installation tests should use a dedicated/sacrificial target or a documented manual procedure until a safe automated test environment exists.
