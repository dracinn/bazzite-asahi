# J313 — MacBook Air (M1, 2020)

- Apple Silicon M1 / T8103
- Device family: MacBook Air 2020
- Identifier: J313
- ARM64
- Development machine family: MacBookAir10,1

## Boot/install target

The first install target is a Fedora Asahi-style boot chain:

1. Asahi Installer prepares the Apple Silicon boot environment.
2. m1n1 loads the Asahi U-Boot path.
3. U-Boot loads the EFI payload.
4. The Bazzite Asahi Atomic image supplies the kernel, initramfs and root filesystem.

The current CI milestone produces the bootable OCI image. The next milestone is
to package that image into the EFI/boot/root layout consumed by the Asahi
installer.
